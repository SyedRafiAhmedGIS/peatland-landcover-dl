# Data sources

| Dataset | What | Access | Licence / terms |
|---|---|---|---|
| Sentinel-2 L2A | 10-20 m multispectral imagery, SCL cloud/shadow layer | Microsoft Planetary Computer STAC API (`sentinel-2-l2a`), no login | Copernicus open data policy |
| CORINE Land Cover 2018 | 44-class land cover, 100 m raster, 25 ha minimum mapping unit | Copernicus Land Monitoring Service, free account, manual download | Free and open, attribute Copernicus / EEA |
| ESA WorldCover | 11-class 10 m land cover (2020/2021) - fallback only | Planetary Computer (`esa-worldcover`) | CC BY 4.0 |

Check each provider's page for the current attribution text before publishing derived figures.
No data files are stored in this repository (`data/` is git-ignored).
